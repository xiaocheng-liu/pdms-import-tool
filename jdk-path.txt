# ============================================================
#  PDMS 数据导入工具 - JDK 路径配置（可选）
# ============================================================
#  什么时候需要改这个文件？
#    - 机器上没有设置 JAVA_HOME，PATH 里也没有 java
#    - 机器上装了多个 JDK，需要固定用其中一个版本
#
#  填写方式：
#    在文件末尾写一行 JDK 安装目录（不要加引号），例如：
#      Windows  ->  C:\Program Files\Java\jdk-17
#      Linux    ->  /opt/jdk-17.0.9
#      macOS    ->  /Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home
#
#  注意：
#    - 该目录下必须存在 bin/java（Windows 为 bin\java.exe）
#    - 以 # 开头的行是注释，会被启动脚本忽略；文件里没有有效路径时会继续
#      按 JAVA_HOME / PATH 查找
#
#  优先级（高 -> 低）：
#    命令行参数 > 环境变量 PDMS_JAVA_HOME > 本文件 > JAVA_HOME > PATH 中的 java
# ============================================================
